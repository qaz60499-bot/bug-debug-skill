# Evidence and integration contract

`scripts/router.mjs` exports `normalizeRequest`, `selectChecks`, `planAnalysis`, `runAnalysis`, `assessSimplification`, `assessRegression`. Harness integration may pass `{execute(invocation,{signal,timeoutMs})}` returning `{status,exitCode,stdout,stderr,startedAt,finishedAt,elapsedMs,truncated}`. Execution, permissions and cancellation remain with the Harness. The standalone transport uses native Node process APIs once, without retry or process supervision.

AnalysisRequest: `root`, `goal`, `scope`, `taskDir`, `mode`, `authorized` (Simplify only), `requiredCapabilities`, `pattern`, `toolRoot`, `options`, `generation`, `timeoutMs`, `maxFiles`, `maxFileBytes`.

Capabilities: `locate`, `structure`, `entries`, `dependencies`, `clones`, `control`, `flow`, `runtime`, `configuration`, `redundancy`. Explicit unsupported capabilities remain gaps. Ambiguous goals are interpreted by Codex before issuing the request. Rules choose tools; the model interprets responsibility, conflict and sufficiency.

AnalysisPlan: required evidence, selected tools with capability assignment, snapshot fingerprint, requested scope, gaps and evidence stopping condition. Deep tools are alternatives; the helper does not launch both.

ToolRun: native executable/argv/cwd, actual tool identity/version/config, input fingerprints, status (completed/failed/cancelled/timed_out/unavailable/unsupported), timing, exit code, raw artifact references, parse evidence and cache eligibility. Native issue exit codes are tool-specific; nonzero output can still carry valid findings. Unknown fields remain in raw records and files.

EvidenceEnvelope: workspace/snapshot/generation/input identity, native static provenance, native category records and JSON pointers, requested/discovered/parsed/unresolved/skipped/truncated coverage, completeness, limitations and native references. `read: NOT_MEASURED` never means the manifest is the tool's actual read set. Runtime observations from delegated workflows must bind instance/time/log origin separately.

ArtifactRef: absolute path, SHA256, native schema, input fingerprint, owner run, generation, committed/failed state, explicit retention owner. Each invocation has a UUID run directory. Raw output is written before its atomic result commit; interrupted directories lack a result commit and cannot be reused. There is no shared mutable latest pointer. Concurrent processes publish different immutable directories; readers validate content hashes. Old snapshots cannot overwrite new snapshots. Cancellation/failure/stale snapshot prevents cache eligibility. This is task-local artifact reuse, not a general persistent index.

Before reusing results, compare workspace/worktree identity, all scoped/project-snapshot source bytes, root/ancestor configuration and lockfile digests, effective options, tool executable/dependency identity and raw hashes. The snapshot is selected after the analyzer route: Knip and dependency-cruiser force project mode, while native search may use scoped mode; neither inventory nor project snapshot proves runtime reachability or external/dynamic closure. The result exposes scanMode, scanPaths and outsideScope=NOT_SCANNED, and cache eligibility is false for unverified non-Native input closure. If an analyzer reads external configuration or mutable dependencies not covered by this identity, disable reuse until those inputs are accounted for. Cross-task reuse, crash-power-loss durability, complete environmental closure and parser sharing are not promised. Do not store credentials or environment variable contents.
